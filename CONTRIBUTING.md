# Contributing

This project is currently in beta-stable RC stage.

Preferred contribution areas:

- Studio One `.song` parsing improvements.
- Crash Analyzer minidump evidence ranking.
- Safer file recovery edge cases.
- UI clarity and release packaging.

Rules:

- Do not modify original `.song` files in destructive workflows.
- New cleanup/recovery features should create separate copies.
- Avoid hardcoded plugin vendor assumptions in crash analysis.
- Keep Windows user experience simple.
